# ESLT v1 target vocabulary

30 glosses for the first working model. Chosen for everyday utility
(greetings, needs, questions, medical/safety) and for being visually
distinct from one another.

**These are target CONCEPTS, not sign descriptions.** The actual EthSL
sign for each entry must be demonstrated by a fluent signer and confirmed
against an EthSL dictionary before recording. Do not invent signs and do
not borrow them from ASL — EthSL is a distinct language.

## Rules for changing this list

- The gloss column is the label used everywhere in code and filenames. Uppercase, hyphenated, ASCII only.
- Adding a gloss after recording starts means every existing signer must come back and record it. Freeze this list before session 1.
- If two glosses turn out to look near-identical in EthSL, merge or drop one rather than hoping the model separates them.
